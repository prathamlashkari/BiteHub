# 🛒 Online Food Store 🍔

An end-to-end web application for browsing, selecting, and ordering food online — built using **React** for the frontend, **Spring Boot** for the backend, and **MongoDB** for data persistence.

---

## 🚀 Features

- 🍽️ Browse a variety of food items categorized by type
- 🔍 Search and filter dishes
- 🛒 Add/remove items to/from cart
- 💳 Place orders securely
- 🧾 View past order history
- 🔐 User authentication & role-based access
- 📦 Admin dashboard to manage products and orders

---

## 🛠️ Tech Stack

### Frontend (React)
- React.js with Hooks
- React Router for navigation
- Axios for HTTP requests
- Tailwind CSS / Bootstrap for UI styling

### Backend (Spring Boot)
- Spring Boot REST APIs
- Spring Security for user authentication
- MongoDB integration via Spring Data MongoDB
- JWT token-based authentication
- Role-based access control (User / Admin)

### Database
- MongoDB (hosted locally or via MongoDB Atlas)
